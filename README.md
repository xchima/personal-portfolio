Wordle Clone

This was a passion project made from me playing this a lot growing up, a browser-based recreation of the popular Wordle word-guessing game, built using HTML, CSS, and JavaScript. This project focuses on implementing interactive game logic, DOM manipulation, user input handling, and dynamic visual feedback without relying on external frameworks.

Features
Five-letter word guessing system with a limited number of attempts
Dynamic tile feedback that indicates whether a letter is correct, misplaced, or not present in the secret word
Custom word dictionary for validating guesses and selecting secret words
On-screen and physical keyboard input
Game-state management to track guesses, attempts, and win/loss conditions
Responsive interface designed to recreate the core Wordle experience
Modular JavaScript structure, including a separate dictionary file for managing valid words
Technologies
HTML — Page structure and game board
CSS — Layout, styling, animations, and visual feedback
JavaScript (ES6) — Game logic, event handling, DOM manipulation, and word validation
Git & GitHub — Version control and project hosting
GitHub Pages — Deployment and live website hosting
What I Learned

Building this project strengthened my understanding of JavaScript fundamentals and front-end development, particularly working with arrays, functions, event listeners, conditional logic, and DOM manipulation. I also gained experience organizing JavaScript into separate modules and using ES6 import/export functionality to keep the application's dictionary and game logic separated.

The project also gave me hands-on experience with GitHub Pages deployment, including organizing the project directory, configuring relative file paths, and preparing a front-end application for deployment in a production environment.
